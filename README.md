### 📖 stepin

> **「絶対に継続できる日記アプリ」** をコンセプトに、アプリ開発サークルの新入生プロジェクトとして3人で開発したモバイルアプリです。

| 項目 | 内容 |
|------|------|
| **開発形態** | チーム開発（3名） |
| **開発期間** | 約4か月 |
| **使用技術** | React Native / TypeScript / Expo / Git / GitHub |
| **担当** | ストリーク機能・設定画面・ウォークスルー画面・リマインダー機能（一部） |

#### ✨ 工夫したこと

- **継続日数を視覚的に伝えるストリーク機能**を実装し、日記を続けたくなる体験を意識
- **初めて利用するユーザーでも迷わず使い始められる**よう、ウォークスルー画面を設計・実装
- 設定画面では、ユーザーが自分に合った利用環境を整えられるよう、**操作しやすいUI**を意識

### ✅ Task Manager

> **「実行したくなる・続けたくなる」をコンセプトに開発した、個人向けタスク管理アプリ**です。

| 項目 | 内容 |
|------|------|
| **開発形態** | 個人開発 |
| **開発期間** | 約1か月 |
| **使用技術** | React Native / TypeScript / Expo / AsyncStorage / Git / GitHub |
| **担当** | 要件定義・UI/UX設計・アプリ設計・フロントエンド実装 |

#### ✨ 工夫したこと

- **管理するよりも実行し、積み上げを実感する**ことを重視したタスク管理アプリとして企画・設計
- タスク完了時に作業時間・コメントを記録し、積み上げログとして一覧表示することで、**日々の振り返りや達成感につながる体験**を実現
- **継続状況をカレンダー上の色の変化で可視化**し、自分の努力や積み重ねを直感的に実感できるUIを設計・実装
- シンプルで迷わず操作できるUIを目指し、**操作回数を減らした画面設計とコンポーネント化による保守性・拡張性**を意識

#### 🔗 Links

- 📦 **Repository**： [GitHubはこちら](https://github.com/taiga-ui/Task-Manager)
